An Android app for Live Datamoshing

Datamosh records one take as a sequence of segments. Continue the take in
datamosh mode to carry motion from earlier segments forward, or insert a clean
segment to reset the effect. Videos are saved locally to the device gallery.

## Building

The project builds from the command line with the included Gradle wrapper:

```console
./gradlew :app:assembleRelease
```
